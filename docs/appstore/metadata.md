## Description — en-US
Playlist URL Extractor is a small menu bar utility that turns a public playlist into a plain list of video links.

Paste a playlist link (or just its ID), press Extract Links, and every video link in the playlist appears in a list you can copy to the clipboard or save as a .txt file. Handy for research notes, course outlines, sharing reading lists with a team, or importing links into other tools.

Features
• Lives in the menu bar — no Dock icon, no windows to manage
• Works with public and unlisted playlists of any length
• Shows each video's title next to its link
• Private or deleted videos are skipped and counted
• Duplicates are removed automatically
• Copy all links at once or save them as a plain text file
• Clear messages for private, deleted or unsupported playlists, quota limits and network problems
• Optional Launch at Login
• English and Turkish

How it works
The app works with public YouTube playlists and reads them through the official YouTube Data API (YouTube API Services). It does not download, play or store videos, and it never asks for an account or password. Only the playlist ID is sent; no personal data is collected.

Playlist URL Extractor is an independent app. It is not affiliated with, endorsed or sponsored by YouTube or Google. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms); see also the Google Privacy Policy (https://policies.google.com/privacy).

## App Review notes (English — Review Information → Notes)

Thank you for reviewing Playlist URL Extractor 2.0.0.

What changed since the previous submission:
• The app no longer reads or parses web pages. Playlist data now comes exclusively from the official YouTube Data API v3 (playlistItems.list / playlists.list), called through our own server at api.salihgencer.com, which holds the API key. The app only receives video IDs and titles.
• It does not download, play, cache or modify any video or audio content. It only lists the public watch links of a playlist the user provides, so they can copy them or save them as a text file.
• New original app icon (a list sheet with a link badge) and name/metadata without third-party trademarks. In-app attribution "Uses YouTube API Services. Not affiliated with YouTube or Google." plus links to the YouTube Terms of Service and Google Privacy Policy (gear menu), as required by the YouTube API Services Developer Policies.

How to test:
1. Launch the app. It is a menu bar app (LSUIElement), so it has no Dock icon or window; the popover opens automatically on first launch. Afterwards click the list icon in the menu bar (if the menu bar is crowded on a notched display, launch the app again from Finder/Launchpad and the popover opens).
2. Paste this public playlist from the official "Google for Developers" channel:
   https://www.youtube.com/playlist?list=PLOU2XLYxmsIIAOskSyap13n9W-xOt_GP5
   (or just the ID: PLOU2XLYxmsIIAOskSyap13n9W-xOt_GP5)
3. Click "Extract Links". The playlist title and every video link appear.
4. Click "Copy All" (links are copied to the clipboard) or "Save as Text File…" (a save panel lets you choose the location; the app is sandboxed and only writes where you choose).
Optional — a long playlist that exercises paging (official channel uploads): UU_x5XG1OV2P6uZZ5FSM9Ttw
Optional — error handling: enter "PLdoesnotexist000" to see the "Playlist not found" message.

No account, login or in-app purchase is required. No personal data is collected.
